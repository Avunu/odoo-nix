usage: odoo-nix [-h] [--version] <command> ...

odoo-nix's standards tools for Odoo projects and addon repositories. See
https://github.com/Avunu/odoo-nix/tree/main/docs/standards.

options:
  -h, --help   show this help message and exit
  --version    show program's version number and exit

commands:
  <command>
    check      the lint gate's checks no hook makes: manifests, icons, submodules
    ci         the steps the workflows run (auto-merge, relock, release, bump, drift)
    config     print a resolved configuration value (lists one item per line)
    gate       run a CI gate: lint or test
    data-path  print the absolute path of a file shipped in the product's data
    pin-path   print a directory holding a flake.lock input, fetched and narHash-verified
    policy     the commit-msg hook and the pr-policy check
    profile    show the resolved profile, validate an org profile, list the built-ins
    ratchet    the coverage floor only rises
    repo       repository settings, rulesets, the scorecard, rollouts and the fleet
    sync       render, write or check the odoo-nix managed files of the checkout in the current
               directory
